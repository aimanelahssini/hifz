# Quran translations

Plain-text ayah files from [Tanzil](https://tanzil.net/trans/), UTF-8, 6236 lines each
(one per ayah, same order as the Arabic Uthmani text).

| File | Language | Translator |
|------|----------|------------|
| `en.sahih.txt` | English | Saheeh International |
| `fr.hamidullah.txt` | French | Muhammad Hamidullah |
| `tr.diyanet.txt` | Turkish | Diyanet İşleri |
| `id.indonesian.txt` | Indonesian | Indonesian Ministry of Religious Affairs |
| `es.cortes.txt` | Spanish | Julio Cortés |

Keep the files unmodified. Credit Tanzil / the translators if you redistribute them.
